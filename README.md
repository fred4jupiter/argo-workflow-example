# argo-workflow-example

Playground for testing Argo Workflow.

## Prerequisites

You need `k3d` and `kubectl` installed.

## Installation

Run the following command to create a k3d cluster and install Argo Workflow:

```bash
./argo-k3d.sh
```

## Examples

There is a collection of examples in the `examples` directory.

You can find more examples at the [official website](https://github.com/argoproj/argo-workflows/tree/main/examples).
